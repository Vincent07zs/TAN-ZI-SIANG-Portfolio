# Tan Zi Siang — Portfolio hero

Single-page hero. One self-contained file: `index.html` (no build step, no dependencies).

## Publish on GitHub Pages
1. Push these files to a repo.
2. Repo Settings → Pages → Deploy from branch → `main` / root.
3. Open `https://<username>.github.io/<repo>/`

## Edit
- Booking link: search `index.html` for `href="#"` and replace it.
